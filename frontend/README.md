# PJMS Frontend

React + Vite + Tailwind frontend for the PJMS platform.

## Stack

- React 18
- Vite 5
- Tailwind CSS
- React Router
- TanStack Query
- Zustand
- React Hook Form + Zod
- Axios
- Sonner (toast notifications)

## Run

1. `pnpm install`
2. `cp .env.example .env`
3. `pnpm dev`

## Build

- `pnpm build`
- `pnpm preview`
